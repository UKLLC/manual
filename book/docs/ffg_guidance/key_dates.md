# Key dates for uploading files
>Last modified: 03 Aug 2026
<div style="background-color: rgba(0, 178, 169, 0.3); padding: 5px; border-radius: 5px;"><strong>Updated File 1s should be submitted each quarter.</strong></div>

## File 1s  
Dates for LPS to send File 1s to DHCW (Digital Health and Care Wales).

| Window | Window opens on: | File 1 updates to be sent by: |
|---|:---:|---|
| Jan - Feb 2026 | 13 Jan | 03 Feb 2026 |
| Apr - May 2026 | 14 Apr | 05 May 2026 |
| Jul - Aug 2026 | 14 Jul | 04 Aug 2026 |
| Oct - Nov 2026 | 13 Oct | 03 Nov 2026 |

> Instructions for submitting a File 1 are [here](../ffg_guidance/file1s/file1_checklist.md).
## File 2s
There are no specific dates for uploading File 2 (attribute) data. File 2s can be uploaded at any point after the relevant File 1 has been submitted.

> Instructions for submitting a File 2 are [here](../ffg_guidance/file2s/file2_checklist.md).
