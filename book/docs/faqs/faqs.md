## Uploading Data Files

<details><summary>When should we upload data to the TRE?</summary>

* <b>Participant identifiers</b> can be uploaded every quarter as a [<b>File 1</b>](../ffg_guidance/file1s/file1_checklist.md). These uploads should only be done during the three-week long [<b>File 1 windows</b>](../ffg_guidance/key_dates.md#file-1s). If there have been no changes to participants' status or permissions during the quarter, there is no need to submit a File 1.

* Attribute data [(<b>File 2s</b>)](../ffg_guidance/file2s/file2_checklist.md) can be uploaded at any time. Please contact [<b>support@ukllc.ac.uk</b>](mailto:support@ukllc.ac.uk) to let the Data Team know that you intent to upload File 2 data.

<aside class="admonition danger"><p class="admonition-title">Never send any File 1 or File 2 data by email.</p>All data must be transferred to the TRE by following the distinct<a 
href="https://manual.ukllc.ac.uk/docs/ffg_guidance/ffg_intro.html" target="_blank" rel="noopener 
noreferrer">File 1 and File 2 processes.</a></aside>

</details>
