# Introduction: LPS manual
>Last modified: 27 May 2026
<div style="background-color: rgba(0, 178, 169, 0.3); padding: 5px; border-radius: 5px;"><strong>This information is for LPS data managers working with UK LLC.</strong></div>
<br>
It will ultimately provide the all the information and guidance data managers need to work with UK LLC.  

<br>

**UK LLC's website (<a href="https://ukllc.ac.uk/" target="_blank" rel="noopener noreferrer">ukllc.ac.uk</a>)** provides more information about the UK Longitudinal Linkage Collaboration. Researchers interested in working with UK LLC should visit <a href="https://guidebook.ukllc.ac.uk/" target="_blank" rel="noopener noreferrer">**Guidebook**</a>

Resource contents:  

**1) File Formatting Guidance**: how to upload LPS data to the UK LLC Trusted Research Environment (TRE)  

**2) Study Zones**: TRE access for LPS team members to run quality checks on their own linkages 

**3) Metadata Management System (MMS)**: how to upload and update metadata to the TRE

**4) UK LLC Apply**: how to review applications to use LPS data in the TRE

Any queries about the content of this manual should be directed to [**support@ukllc.ac.uk**](mailto:support@ukllc.ac.uk).
