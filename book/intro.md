# Introduction

This Jupyter book is for data managers working with Longitudinal Population Studies (LPS) partnered with UK LLC [link].  
<br>
It will ultimately provide the all the information and guidance data managers need to work with UK LLC.  
<br>
The intended content for this manual is:  
* File Formatting Guidance: how to upload LPS data to the UK LLC Trusted Research Environment (TRE) 
* Study Zones: (content and intro from ResourceHub) 
* Metadata Management System (MMS) guidance: how to ...
* Reviewing applications to use LPS data in the TRE

Any queries about the content of this manual should be directed to [**support@ukllc.ac.uk**](mailto:support@ukllc.ac.uk).
